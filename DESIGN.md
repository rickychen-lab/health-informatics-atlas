# Health Informatics Atlas
Personal learning workspace, not an official KCL website.
Palette: ink #152d35, paper #f5f7f7, teal #176e64, mint #deeee7, slate #677a80, gold #b88539.
Typography: Georgia display for conceptual headings; system sans for UI and lesson text; monospace only for code.
Layout: fixed ink navigation, wide paper workspace; opening lesson route beside an illustrative longitudinal health record. Compact horizontal curriculum rows lead into a spacious reader with sticky section navigation. Practical work has a dedicated lab surface.
Principle: show the transformation from messy records to careful reasoning. The trace plot is a meaningful interactive teaching aid, not a decorative stock image. Restrained motion, keyboard access, readable line lengths, mobile navigation, visible progress, Chinese on demand.
Design reference reviewed: https://github.com/anthropics/skills/blob/main/skills/frontend-design/SKILL.md . No third-party code installed.
